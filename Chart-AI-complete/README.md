# Chart AI — Commercial UI Starter

ローカルで動かせる株式リサーチ・ダッシュボードです。

## 含まれる機能
- 銘柄名・ティッカー・JPX 4桁コード検索
- 1日（5分足） / 1ヶ月 / 3ヶ月 / 6ヶ月 / 1年 / 2年 / 5年 / 全期間
- 株価・MA20/50/200・ボリンジャーバンド
- 出来高、RSI、MACD、Stochastic、ROC、ATR、標準偏差
- テクニカル材料の内訳と上昇寄り/下降寄りスコア
- ファンダメンタル：成長性、収益性、バリュエーション、財務健全性、株主還元
- 銘柄発掘（Yahoo Financeスクリーナーのページング）
- 日本株 / 米国株切替
- ウォッチリスト（ブラウザのlocalStorage）
- レスポンシブな商用ダッシュボードUI

## 起動
Windowsなら `start.bat` をダブルクリック、または:

```powershell
python -m pip install -r requirements.txt
python app.py
```

ブラウザで `http://127.0.0.1:5000/` を開きます。

## 注意
データ取得はYahoo Finance/yfinanceに依存します。取得可能な銘柄・市場・時間足・フィールドは提供元の仕様や市場時間に左右されます。スコアは予測モデルではなく、ルールベースの情報整理です。実運用前には、データ利用条件、免責表示、利用規約、プライバシーポリシー、エラー監視、レート制限、認証・課金基盤などを別途整備してください。
